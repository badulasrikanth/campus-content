📚 Campus Connect – College Events Website
📌 Project Overview

Campus Connect is a web application designed to display information about college events, sports activities, and student clubs.
The website helps students stay updated with campus activities and encourages participation in events and clubs.

This project is developed using HTML, CSS, and JavaScript with a focus on modern design and smooth animations.

🎯 Objectives

Provide a centralized platform for college event information

Display details about sports tournaments

Showcase different student clubs

Create a responsive and visually appealing website

Practice front-end web development skills

🛠 Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and animations

JavaScript – Interactivity and dynamic behavior

✨ Features
--> Responsive navigation bar

--> Beautiful hero section

--> Event cards with hover animations

Sports section displaying tournaments

Student clubs section

Typing animation in the hero section

Dark mode toggle
